# NNG4 Solutions

My solutions to the [Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/NNG4), completed as a first playthrough.

These are intentionally presented as the tactics I wrote while learning. Some proofs can be cleaned up, steps can be merged, and a few steps are redundant. That is part of the record: this repository is a first-try solution archive, not a collection of polished canonical proofs.

## Scope

The snippets are copied from my completed game levels. They are tactic blocks rather than standalone Lean files, so they do not compile independently outside the Numbers Game environment. This repository is not affiliated with, endorsed by, or a redistribution of the Numbers Game.
